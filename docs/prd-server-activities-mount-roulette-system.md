# PRD: AzerothCore --- Server Activities & Mount Roulette System

## 1. Название проекта

**Server Activities & Mount Roulette System**

Система активностей для AzerothCore 3.3.5a, которая добавляет ежедневные
активности для игроков 80 уровня+, награды в виде круток и интерфейс
случайного получения маунтов.

------------------------------------------------------------------------

# 2. Цели проекта

## Основные цели

-   Повысить удержание игроков после достижения 80 уровня.
-   Добавить новые цели кроме экипировки и рейдов.
-   Оживить открытый мир.
-   Создать коллекционную систему маунтов.
-   Создать ежедневную игровую мотивацию.

------------------------------------------------------------------------

# 3. Ограничения

## Требование уровня

Все активности доступны только:

    Level >= 80

Игроки ниже 80 уровня:

-   не получают награды;
-   не получают крутки;
-   не имеют доступа к интерфейсу.

Отвечает за:

# 6. Активности игроков

Каждая активность в версии 1.0:

    1 раз в день

Все значения должны быть в конфиге.

------------------------------------------------------------------------

# 7. Список активностей

## Dungeon Completion

Условие:

-   завершение подземелья.

Награда:

-   Mount Spins.

------------------------------------------------------------------------

## Heroic Dungeon

Условие:

-   завершение героического подземелья.

Награда:

-   увеличенное количество круток.

Условие:

-   убийство босса рейда.

-   игрок был в рейде;
-   игрок участвовал;
-   игрок находился рядом.

Условие:

-   победа на поле боя.

Награда:

-   Mount Spins.

------------------------------------------------------------------------

## World Boss

Условие:

-   участие в убийстве мирового босса.

------------------------------------------------------------------------

## Achievement

Условие:

-   получение достижения.

------------------------------------------------------------------------

## Exploration

Условие:

-   открытие новых зон;
-   исследование мира.

------------------------------------------------------------------------

## Profession Activities

Примеры:

-   редкий крафт;

-   создание предметов.

## Fishing Events

Пример:

     |

    Result

# 15. Дубликаты

Если маунт уже изучен:

    Mount Shards

Выдаются вместо него.

------------------------------------------------------------------------

# 16. Конфигурация

Все значения в конфиге:

-   стоимость крутки;
-   количество награды;
-   лимиты;
-   шанс выпадения;
-   список наград;
-   стоимость shards;
-   pity.

Пример:

``` ini
MountRoulette.RequiredLevel = 80

MountRoulette.SpinCost = 1

MountRoulette.EpicPity = 50

MountRoulette.LegendaryPity = 100
```

------------------------------------------------------------------------

# 17. GM Debug Commands

## Добавить крутки

    .mroulette addspins Player 10

------------------------------------------------------------------------

## Информация игрока

    .mroulette info Player

Показывает:

-   крутки;
-   pity;
-   ежедневные активности.

------------------------------------------------------------------------

## Тестовая крутка

    .mroulette spin Player

------------------------------------------------------------------------

## Выдать маунта

    .mroulette reward Player spellId

------------------------------------------------------------------------

## Сброс активности

    .mactivity reset Player

------------------------------------------------------------------------

## Запустить событие

    .mevent start invasion

------------------------------------------------------------------------

## Остановить событие

    .mevent stop invasion

------------------------------------------------------------------------
